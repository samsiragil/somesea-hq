# Arsip

`Releases/` disiapkan untuk snapshot rilis berikutnya. Belum ada riwayat sebelum versi 0.1.0.

Sebelum mengubah arah atau keputusan, simpan salinan dokumen yang terdampak ke `Releases/YYYY-MM-DD-vX.Y.Z/`, lalu perbarui changelog. Untuk snapshot seluruh HQ, buat ZIP di luar folder HQ agar arsip tidak memasukkan dirinya sendiri.

Arsip mingguan proyek selesai dapat memakai `Projects/P-XXX/`. Jangan hapus bukti persetujuan, penerimaan hasil, atau pembayaran hanya karena proyek ditutup.
