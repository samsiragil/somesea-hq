# Pustaka aset

- `Incoming/`: ekspor percakapan dan berkas lama yang belum diperiksa.
- `Brand/`: logo, avatar, warna/font yang telah dikonfirmasi.
- `Portfolio/`: demo, studi kasus, dan bukti izin publikasi.
- `Business-OS-Legacy/`: salinan dashboard lama setelah diterima dan diperiksa.

Folder-folder ini disiapkan tanpa aset contoh. Tidak ada file dashboard lama yang berhasil dipulihkan pada versi 0.1.0.

Pertahankan file asal. Catat nama, asal, versi, status, dan lokasi di inventaris. Untuk aset klien, simpan bukti izin penggunaan dan hindari menyalin data pribadi yang tidak dibutuhkan.
